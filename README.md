# fix-my-city

An AI-powered Smart City Complaint Management System designed to streamline how citizens report local issues (like potholes, broken streetlights, or waste management) and help authorities track, prioritize, and resolve them efficiently.

## 🚀 Features

* **User-Friendly Reporting:** Citizens can easily lodge complaints with descriptions, categories, and locations.
* **AI-Powered Categorization:** Automatically analyzes and routes complaints to the correct department using AI.
* **Real-time Dashboard:** Interactive dashboard for city administrators to track pending, in-progress, and resolved issues.
* **Status Updates:** Transparent tracking system so citizens can see the live progress of their reported issues.

## 🛠️ Tech Stack

* **Backend:** Python, Django / FastAPI (Choose your backend)
* **Frontend:** React.js, Tailwind CSS
* **Database:** PostgreSQL / SQLite
* **AI/ML:** (e.g., OpenAI API, Hugging Face, or custom NLP models for categorization)
